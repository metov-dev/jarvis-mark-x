# TASK-03 Две истории кода: что из сентябрьской ветки потеряно в master

**Статус:** Ждёт решения владельца
**Источник:** разбор 09.10.2026

### Зачем:
Похоже, главная причина «чиним, а итог тот же». В репозитории две независимые истории проекта без общего коммита (история переписывалась). Починки сентября живут только в ветке `fix/audio-stack-and-music-playback` и в master не попали. Владелец получает сборку из master — без них.

### Что требуется по запросу:
- Составить список того, что есть в сентябрьской ветке и нет в master (по функциям ядра, не по коммитам).
- Для каждого пункта решить: перенести, уже сделано в master иначе, или не нужно.
- Решения согласовать с владельцем до переноса.

### Контекст:
- `master` — 470 своих коммитов, последний 07.10.2026; `fix/audio-stack-and-music-playback` — 312 своих, последний 25.09.2026. Первые коммиты одинаковые по смыслу, но с разными хэшами.
- Только в сентябрьской ветке: `actions/local_answers.py` (время/погода без модели), `actions/spotify_desktop.py`, `core/confirmations.py` (сигнал вместо слов), кэш голоса, стрим Fish с хеджем на Edge, своя модель слова «Джарвис», фиксы ложных пробуждений, громкость после краха во время приглушения.
- Ещё ветки с отдельной работой: `art/installer-steps` (+38 к origin), `improve/reliability-persona-headless` (194/194 расхождения).

### Согласовано (История решений):
- **09.10.2026**: обнаружено при заведении бэклога. Ничего не переносилось.
- **09.10.2026, разбор:** первая гипотеза («фиксы не доходят до сборки — главная причина») **не подтвердилась**. Master решал те же задачи своими модулями и в основном не хуже: быстрые команды — `core/quick.py`; слово «Джарвис» — `core/wake_kws.py` + `wake_vosk.py`; Spotify Free — `core/media_session.py` (GSMTC); Fish→Edge при молчании Fish — в `main.py`; кэш голоса — `quick.VoiceCache`; программы — `core/win_apps.py` (Microsoft Store через AppsFolder). Сентябрьская ветка устарела как целое.
- Реально полезное из сентябрьской ветки, чего нет в master: (1) погода без модели и разбор города с ослышками/падежами (`actions/local_answers.py`, `city_candidates`) — в master «Шимкенте» даёт «проверьте интернет», условия по-английски; (2) мост к вкладке браузера с адаптерами YouTube/VK/Кинопоиск (`core/media/bridge`) — нужен только для TASK-12.
- **Предложение:** главная — master. Переносить не ветку, а только пункт (1) — в рамках TASK-06. Ветку не удалять до закрытия ядра.
