# TASK-09 Telegram-бот

**Статус:** В очереди
**Источник:** ядро, согласовано 09.10.2026

### Зачем:
Джарвис доступен с телефона, когда владелец не у ПК.

### Что требуется по запросу:
- @Aimyjarvisbot отвечает на текст и голосовые.
- Помнит владельца (досье, задачи).
- Команды на ПК через бота доходят, если ПК включён.
- Напоминания приходят в Telegram.

### Контекст:
- `telegram_bot/` (bot.py, gemini_client.py, memory_store.py, pc_bridge.py, pc_server.py, reminders.py).
- Хостинг: Hugging Face Space + Cloudflare-прокси + Neon (Postgres). Ветка деплоя `deploy-hf` отстаёт от master на 72 коммита.

### Согласовано (История решений):
- **09.10.2026**: карточка заведена.
- **09.10.2026, без голоса:** бот на HF жив: `atabekovch-jarvis-mark-x.hf.space/health` → `{"status":"ok","pc":false}` за 0,6 с. **Связи с ПК нет** (`pc:false`), хотя Джарвис на ПК запущен — проверить, кто держит канал (`pc_server`/watchdog) и запущен ли он. Ответы бота не проверены (нужен телефон владельца).

### Предложения для обсуждения / Вопросы:
- Какая версия бота сейчас живая на HF — проверить `/health` и коммит.
- Нужен ли боту доступ к ПК вообще, или только разговор + напоминания?

### Не делать сейчас (Out of Scope):
- Mini App, 3D-HUD, персоны, звонки через userbot.

### Критерий готовности:
- [ ] Написать «привет» — ответ ≤ 5 с, по делу.
- [ ] Голосовое сообщение — распознано, ответ по смыслу.
- [ ] «Напомни через 5 минут…» — напоминание пришло.
- [ ] «Что ты обо мне знаешь» — отвечает из досье.
- [ ] Владелец подтвердил с телефона.
