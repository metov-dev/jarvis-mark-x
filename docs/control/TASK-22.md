# TASK-22 Сам заговаривает к месту (как Джарвис из фильма)

**Статус:** Идея (согласовано 28.11.2026)
**Источник:** владелец, 28.11.2026 — «не «что тебе нравится», а «вам пора спать», к делу, но не как обычный робот»

### Что требуется:
Одна короткая фраза: факт → вывод → предложение, с иронией, ответ «да/нет». Только по тому, что Джарвис реально видит.

### Темы (первая версия):
1. Отбой: после sleep_time из анкеты идёт серия/игра — «по вашему же расписанию вы спите уже час…», будильник по подъёму.
2. Долго в игре (activity: 3 ч подряд) — перерыв.
3. Утро: погода + пары (study / work_hours) — что надеть.
4. Забытое: завтра пары, будильник не стоит — поставить?
5. Даты: дни рождения (анкета: birthday, family).
6. Сообщение от контакта во время игры — «не стал отвлекать, прочитать?».

### Границы:
Не чаще раза в час; тихо во время звонка и полноэкранного кино (отбой — после серии); «не сейчас/тише» — пауза 3 ч; дважды отмахнулся от темы — больше её не поднимает; выключатель каждой темы в настройках.

### Контекст:
core/activity.py (что смотрю/играю), core/about_me.py (sleep_time, wake_time, birthday, family), clock (будильник), погода, core/study, contacts (входящие), core/dialog_context.py ResumeObserver, напоминания о перерывах (уже есть, 120/60 мин).
