# TASK-22 Сам заговаривает к месту (как Джарвис из фильма)

**Статус:** В работе — v1 сделана 28.11.2026, ждёт проверки владельцем
**Источник:** владелец, 28.11.2026 — «не «что тебе нравится», а «вам пора спать», к делу, но не как обычный робот»

### Что требуется:
Одна короткая фраза: факт → вывод → предложение, с иронией, ответ «да/нет». Только по тому, что Джарвис реально видит.

### Темы (первая версия):
1. Отбой: после sleep_time из анкеты идёт серия/игра — «по вашему же расписанию вы спите уже час…», будильник по подъёму.
2. Долго в игре (activity: 3 ч подряд) — перерыв.
3. Утро: погода + пары (study / work_hours) — что надеть.
4. Забытое: завтра пары, будильник не стоит — поставить?
5. Даты: дни рождения (анкета: birthday, family).
6. Сообщение от контакта во время игры — «не стал отвлекать, прочитать?».

### Границы:
Не чаще раза в час; тихо во время звонка и полноэкранного кино (отбой — после серии); «не сейчас/тише» — пауза 3 ч; дважды отмахнулся от темы — больше её не поднимает; выключатель каждой темы в настройках.

### Контекст:
core/activity.py (что смотрю/играю), core/about_me.py (sleep_time, wake_time, birthday, family), clock (будильник), погода, core/study, contacts (входящие), core/dialog_context.py ResumeObserver, напоминания о перерывах (уже есть, 120/60 мин).

### Сделано в v1 (28.11.2026) — core/nudges.py, инструмент `nudges`
- Отбой: после sleep_time из «Обо мне» (через 20 мин … 4 ч, через полночь тоже), если играет или только что досмотрел видео. Серию не перебивает — ждёт конца/паузы. Предлагает будильник на wake_time.
- Будильник: 20:00–24:00, завтра есть пары, а будильника до первой пары нет.
- День рождения владельца (дата из «Обо мне»), после 9:00.
- Правила: раз в час (общий счётчик с перерывами), тихо в звонке/разговоре/ответе/подтверждении и при выключенном микрофоне; «не сейчас/тише/потом» — пауза 3 ч; дважды «нет» — тема выключается; состояние в nudges.json.
- Голосом: «не напоминай про отбой», «не заговаривай сам», «помолчи пару часов», «что ты сам подсказываешь», «проверь подсказку про отбой» (срабатывает сразу — для проверки днём).

### Не вошло в v1
- Выключатели тем в окне настроек — пока только голосом.
- Дни рождения близких (в анкете только имена, без дат).
- Сообщение от контакта во время игры.
- Долго в игре — уже делает break_reminder; утро с погодой — briefing.

### Проверка владельцем
Сказать «Джарвис, проверь подсказку про отбой» → он должен произнести подсказку; ответить «да» → поставит будильник.
