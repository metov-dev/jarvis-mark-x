# TASK-06 Время и погода

**Статус:** В очереди
**Источник:** ядро, согласовано 09.10.2026

### Зачем:
Простые вопросы должны отвечаться мгновенно и правильно, без похода в модель.

### Что требуется по запросу:
- Время и дата — сразу.
- Погода сейчас и прогноз на завтра для своего города и для названного.
- Правильный город (Шымкент, а не Москва и не «по IP»).

### Контекст:
- `actions/weather.py` (Open-Meteo), `core/location.py`, `core/clock.py`.
- Локальные ответы без модели (`actions/local_answers.py`) есть только в сентябрьской ветке (TASK-03).
- `default_city` в `config/api_keys.json` не задан.

### Согласовано (История решений):
- **09.10.2026**: карточка заведена.

### Предложения для обсуждения / Вопросы:
- Город по умолчанию — Шымкент? Записать в настройки.

### Не делать сейчас (Out of Scope):
- Утренний брифинг, новости.

### Критерий готовности:
- [ ] «Который час» — верное время ≤ 2 с.
- [ ] «Какая погода» — погода в Шымкенте ≤ 3 с, по-русски, без ошибок в склонениях.
- [ ] «Погода в Алматы завтра» — прогноз для Алматы.
- [ ] Ослышка («в Шимкенте») всё равно даёт Шымкент.
- [ ] Владелец подтвердил голосом.
