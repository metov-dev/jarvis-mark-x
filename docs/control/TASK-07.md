# TASK-07 Таймер и напоминание

**Статус:** В очереди
**Источник:** ядро, согласовано 09.10.2026

### Зачем:
Напоминание, которое не сработало, хуже, чем никакого: владелец на него рассчитывает.

### Что требуется по запросу:
- Таймер на N минут — один раз, не по кругу.
- Напоминание «через 10 минут позвонить маме» / «завтра в 9 …».
- Будильник на время.
- Срабатывает, даже если Джарвис был свёрнут; переживает перезапуск.

### Контекст:
- `actions/sleep_timer.py`, `core/smart_reminders.py`, `core/clock.py`, `clock.json`, `telegram_bot/reminders.py`.
- Известные баги из прошлого: «на в 19:00» (двойной предлог); «через 10 минут позвонить маме» — всё уходит во «когда».

### Согласовано (История решений):
- **09.10.2026**: карточка заведена.

### Предложения для обсуждения / Вопросы:
- Напоминание дублировать в Telegram, если ПК выключен?
- Как звучит срабатывание: сигнал + фраза?

### Не делать сейчас (Out of Scope):
- Повторяющиеся напоминания по расписанию, календарь Google.

### Критерий готовности:
- [ ] «Таймер на 2 минуты» — через 2 мин сигнал и фраза, один раз.
- [ ] «Напомни через 3 минуты выпить воды» — через 3 мин говорит «выпить воды».
- [ ] «Разбуди в 7:30» — подтверждает без двойного предлога, срабатывает.
- [ ] Перезапуск Джарвиса не теряет напоминание.
- [ ] Владелец подтвердил голосом.
