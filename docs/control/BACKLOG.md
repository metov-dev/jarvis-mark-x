# Бэклог проекта JARVIS

## Правила (согласовано 09.10.2026)
1. **Один список.** Задачи живут только здесь. `tasks/todo.md` перенесён в `tasks/archive/`.
2. **«Готово» ставит владелец** — после проверки голосом на живой программе, не по тестам.
3. **В работе — одна задача.** Следующую не начинаем, пока текущая не закрыта.
4. **Одна карточка на функцию.** Мелкие ошибки — строкой в карточку своей функции.
5. **Правит один агент.** Другие ИИ (Gemini, ChatGPT) в проект не пишут. Работа — только через этот бэклог.
6. **Новые функции заморожены**, пока ядро (TASK-04…TASK-09) не в «Готово».
