# TASK-14 Челка: вау-вид, умное появление, ручной вызов

**Статус:** Идея
**Источник:** идея владельца, 09.10.2026

### Зачем:
Челка — лицо Джарвиса на экране. Сейчас она недостаточно красивая и иногда мешает (в играх).

### Что требуется по запросу:
- Челка круче и красивее, анимации с вау-эффектом.
- Плавно и красиво появляется и так же уходит.
- **В играх не появляется вообще.**
- В остальное время сама появляется в нужный момент.
- Ручной режим: мышь в верхний центр экрана → появляется кнопка → нажал → челка открыта и не уходит; свернуть — отдельной кнопкой.

### Улучшения (предложение Claude):
- **Появление «как жидкость»:** капля вытекает из верхнего края, растягивается в капсулу с упругим доводом (spring), содержимое проявляется из размытия. Уход — обратно в край. Без появления «из ниоткуда».
- **Режимы размеров:** точка (живой индикатор) → капсула (статус: трек, таймер) → карточка (ответ Джарвиса, погода, напоминание) — переходы между ними одной плавной трансформацией, как Dynamic Island.
- **Говорит — видно:** во время речи по краю идёт волна в такт голосу; слушает — мягкое свечение реагирует на громкость.
- **«Нужный момент» — конкретно:** зовут «Джарвис», говорит ответ, сработал таймер/напоминание, сменился трек, пришло сообщение в бота. Через 4 с после события — сворачивается.
- **Игровой режим без ложных срабатываний:** прятать, если активное окно — полноэкранное или «окно без рамок» на весь экран, или процесс в списке игр (Steam, Epic, CS2, COD, GTA). Во время игры события копятся и показываются после выхода.
- **Ручной вызов:** горячая зона 200×6 px сверху по центру; при наведении 300 мс — появляется маленький «язычок», клик — челка закреплена (значок булавки). Повторный клик по булавке или Esc — свернуть.
- **Не мешает работе:** клики сквозь челку, когда она в режиме точки; не перекрывает полноэкранное видео.

### Референс владельца (09.10.2026): ролик «Design 03», остров Grok Bot
Владелец: «челка там работает настолько чётко, хочу такое», **«мне очень нравится его появление — не забыть»**.
Разобрано по кадрам: ролик — 8 статичных состояний, смена раз в секунду, **самой анимации перехода в файле нет** (кадры меняются мгновенно). Появление владельцу, видимо, запомнилось по оригиналу. Поэтому движение я проектирую сам, а состояния беру из ролика:
1. **Появление:** талисман «рождается» из поля мелких частиц — частицы расходятся дугами, в центре шар с глазами-таблетками и два мелких спутника.
2. **Рабочий:** слева круглый талисман со значком, рядом список шагов («Start working / Prep workspace / Copy outputs»), активный шаг ярче; справа 4 цветные капсулы — что делают помощники.
3. **Думает:** талисман крупнее, спиннер и строка статуса, внизу фиолетовое свечение; справа колонка из 4 цветных точек.
4. **Ошибка:** красное свечение снизу, талисман с «сонными» глазами и красной точкой, кнопка «повторить».
5. **Пусто / ждёт файл:** пунктирная рамка, квадратный талисман, подсказка и значки типов файлов.
6. **Файл над островом:** зелёное свечение, талисман раскрывает «воронку» и глотает файл.
7. **Загрузка:** полоса прогресса с «бегунком» и процентами, зелёное свечение.
8. **Готово:** возврат в «рабочий», у талисмана другой взгляд (довольный).
Те же состояния показаны и как виджет экрана блокировки в 3 размерах — один талисман на всех поверхностях.

**Что берём для Джарвиса:**
- **Цвет состояния — свечением по нижнему краю** (слушает — голубое, думает — фиолетовое, ок — зелёное, ошибка — красное). Читается с первого взгляда, не нужен текст.
- **Талисман с выразительными глазами** вместо статичной картинки: моргает, косится на источник звука, «спит» при ошибке. Для Джарвиса — свой талисман в стиле реактора, не копия Grok.
- **Остров меняет форму одним движением** между «точка / капсула / карточка» (см. выше), содержимое внутри перетекает, а не мигает.
- **Правая колонка цветных точек** = фоновые задачи Джарвиса (таймер, загрузка, напоминание, медиа), у каждой свой цвет.
- **Файл на остров** — состояния 5–7 есть и у нас (`core/dropped_file.py`, тест `test_island_live`): оформить так же.
- **Ошибка с кнопкой «повторить»**, а не молчание.
- **Появление из частиц** — главный «вау»: делаем с нуля (Canvas/GPU-частицы на PyQt), скорость 0,6–0,9 с, пружинный довод в конце.
**Не берём:** названия и персонажа Grok, текстовые заглушки, виджеты iPhone.
**Нужно от владельца:** остальные 2 ролика из трёх и, если есть, оригинал с движением — по ним точнее перенесу тайминг появления.
