# TASK-05 Музыка: включить, пауза, громкость

**Статус:** В очереди
**Источник:** ядро, согласовано 09.10.2026

### Зачем:
Самая частая бытовая команда. Сейчас, по словам владельца, работает неправильно.

### Что требуется по запросу:
- Включить песню / артиста / «что-нибудь спокойное» в Spotify.
- Пауза, дальше, следующий трек, громкость тише/громче.
- Честный ответ при ошибке (не «запущено», если не запустилось).

### Контекст:
- `actions/music_player.py`, `actions/spotify_controller.py`, `actions/spotify_premium.py`, `tools/spotify/`, `core/media_session.py`, `core/ducking_controller.py`.
- Spotify без Premium: Web API player = 403 → пауза/play через Windows GSMTC.
- Spotify из Microsoft Store — путь запуска отличается (фикс есть только в сентябрьской ветке, см. TASK-03).

### Согласовано (История решений):
- **09.10.2026**: карточка заведена.

### Предложения для обсуждения / Вопросы:

- После ответа Джарвиса громкость должна вернуться ровно к прежней — подтвердить.

### Не делать сейчас (Out of Scope):
- Яндекс Музыка, YouTube Music, фильмы.

### Критерий готовности:
- [ ] «Джарвис, включи <артист>» — играет нужный артист ≤ 5 с.
- [ ] «Пауза» / «дальше» / «следующий трек» — срабатывает ≤ 1 с, без лишних слов.
- [ ] «Сделай тише» / «громче» — меняется громкость.
- [ ] После ответа Джарвиса громкость музыки возвращается как была.
- [ ] Spotify закрыт → Джарвис сам открывает или честно говорит, что не смог.
- [ ] Владелец подтвердил голосом.
