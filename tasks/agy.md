## Задача 1. Подгрузка последних заметок Obsidian в системный промпт

Сейчас Джарвис видит vault только по запросу («что я записывал про…»). Нужно, чтобы при старте сессии в системный промпт попадали последние заметки.

- Vault: путь в `config/obsidian.json`, действия — `actions/obsidian.py` (`obsidian_action`: write / append_daily / search / read / list).
- Добавь в `actions/obsidian.py` функцию `recent_notes_digest(limit=5, max_chars=1500) -> str`: заголовки и первые строки последних изменённых заметок (включая Daily), одним блоком, без обрыва посреди слова. Нет vault или он пуст — пустая строка, без исключений.
- Подключи результат в сборку системного промпта в `main.py` (ищи рядом со строкой про «Запомнил», ~1320). Менять только место сборки промпта, больше ничего.
- Выключатель: переменная окружения `JARVIS_OBSIDIAN_DIGEST=0` отключает подгрузку.
- Тесты: пустой vault, нет vault, лимит символов, порядок по дате изменения, выключатель.
- Готово, когда: тесты зелёные, `python test_obsidian.py` зелёный, в промпте виден блок заметок (покажи фрагмент).
